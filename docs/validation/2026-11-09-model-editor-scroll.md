# 模型配置窄窗滚动与焦点显露

2026-11-09，#20 的源码 Mac 原生修复与部分矩阵验证。开发应用使用源码 runtime，尚未纳入 ZIP。隔离配置沿用 `.artifacts/settings-layout/`，31 个合成模型、本地占位接口，不调用模型，不更改用户全局配置。

## 问题与修复

修复前在 1184×1104 截图像素（约592×552逻辑像素）窗口内，名称焦点按 Tab 到上下文后，控件仍在视口外；截图只显示表单顶部，固定操作栏正常。不是仅凭 AX 树存在离屏字段作判断。

安装的 gpui-base 0.9.0 Input 在 prepaint 调用 `request_autoscroll`；gpui-pre 0.3.11 的普通 Div 不消费该请求，而 List 实现了消费。保留当前 ScrollHandle / 原表单，使用已有 `on_children_prepainted` 支持这条原生请求：只处理本表单焦点，按实际视口边缘调整必要的纵向偏移，在下一帧重画。不拦截 Home/End、方向键或其他输入行为，也没有另造全局滚动系统。

表单禁止 flex 收缩，保留实际内容滚动高度。输入字段、能力和接口类型用不参加 Tab 顺序的焦点祖先，在实际焦点或视口变化时请求显露整个字段/标签或控件组。记录实际子焦点，避免同组按钮间切换时遗漏；只在变化时请求，因此允许用户手动滚离当前焦点，不持续拉回。
