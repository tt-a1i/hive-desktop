# 将次要入口收进更多，保留会话导航空间

2026-11-09。

## 依据与场景

本机只读查看Cindy 0.1.128的真实主界面：常驻新建/搜索等少量入口，次要能力由“更多”承载，项目/会话占据侧栏主体。这是本次原生观察，不扩大为Cindy全部体验已复验，也不复制其权限或协作模型。

Hive此前八个常驻功能行占据侧栏上部。实际1184×1000截图像素窄窗，三条真实主控/Worker历史会话在AX树中存在，却在可见区域之外，用户必须先滚动。做完后的可观察目标是同一窗口能直接看到三条会话，同时已有功能仍可到达；否则多会话切换成本随内容持续增加。

## 改动

- 新建、搜索、团队成员、协作概览保持常驻；工作流、工作区记忆、工作区终端和已归档会话移入“更多”。常驻功能行由8减为5，没有删能力或新增存储。
- 复用现有PopupMenu与原页面处理函数，保留原禁用条件；工作流/记忆/终端当前页有选中背景及菜单勾号。项目功能与全局归档用分隔线区分。
- 窄窗切换页面仍沿用原处理函数收起侧栏。归档仍是原搜索对话框，不改变归档语义。
- Windows现有UI脚本“导航未覆盖设置”的负向判断由已移入菜单的终端改为仍常驻的更多入口，避免旧判断失去作用。仅改选择器，UTF-8 BOM保留，未宣称在Windows运行。
