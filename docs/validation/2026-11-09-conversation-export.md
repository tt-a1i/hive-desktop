# 当前会话的 Markdown 导出（#16，进行中）

对应 [#16](https://github.com/tt-a1i/hive-desktop/issues/16)。聊天标题栏增加“导出当前对话”，解决逐条复制长对话及折叠执行过程容易遗漏的问题。复用当前已加载的聊天投影，没有新增后端协议、厂商调用或聊天store。

## 行为

打开窗口时捕获固定快照，标明工作区、后端和会话编号。默认导出可见正文、汇报、普通附件名称/类型/大小/编号、汇报产物路径，以及可用的图片数量；不打包附件本体。图片投影未保留文件名时直接说明未提供，不编造名称。

用户可分别选择思考和工具过程；原生隐藏的思考不解码，进行中/中断标记保留，工具输入、结果、补丁和诊断分别输出。工具结果使用长于正文内反引号连续段的Markdown围栏，避免原始代码块破坏文档结构。正文原有Markdown保留。

快照只取实际渲染的消息，成员汇报取可见正文，不使用包含注入包装的原始载荷。未发送草稿、其他会话、隐藏系统上下文均不导出。运行中的会话标记当前回合可能不完整。该入口不宣称导出原生所有分支或压缩前未加载的历史。

预览只显示前10,000个字符，并明确提示复制与保存仍包含完整内容；复用键盘滚动阅读区。复制完整Markdown或使用系统保存对话框，保存期间锁定选项，取消及失败保留同一份快照。

图片原有临时文件写入再替换逻辑移动到 `file_save.rs`，两处共享。默认文件名前缀为Hive，替换Windows禁止的字符并去掉尾部点/空白；未新增依赖。

## 已取得的证据

- `.artifacts/conversation-export/seed.mjs` 使用真实Hive HTTP/SQLite及Pi SessionManager创建原生历史和上传副本。正文、思考、工具及成员汇报全部为明确的合成验证数据，不是模型执行结果。模型元数据固定openai/gpt-6.1-terra，回环不可达提供商、离线，无厂商请求。
- Mac源码原生窗口打开快照，两个过程开关初始关闭；实际系统Save取消后快照保留。系统对话框保存中文命名的 `project/默认导出.md`，33,321字节、11,322字符，包含长正文完整尾部，超过预览上限。
- 实际原生开关分别切到开启；系统保存 `project/Hive-项目讨论 _ 导出验证.md`，包含思考、工具输入/结果及正确的嵌套围栏。该次保存遇到原生自动化/窗口超时，最后通过显式Go To Folder重选已有项目目录后保存；实际文件读取断言通过，不以超时返回猜测是否成功。
- 两份文件分别核对中文多行、1200段长正文、附件名、图片数量、可见汇报及产物。默认版排除思考/工具，完整版包含；均排除另一会话、隐藏上下文、未发送草稿、原始注入包装、附件正文及图片base64。见 `ui-content-receipt.json`。
- 实际草稿文件保持 `DO_NOT_EXPORT_DRAFT · 保留未发送草稿`，Hive messages仍为0，RPC日志没有chat.prompt。只读快照不创建任务或消息。
- 格式行为检查 `cargo test --locked --manifest-path apps/desktop/Cargo.toml export_preserves_selected_content -- --nocapture`：1通过，覆盖四种选项组合、围栏及Windows文件名。原有 `save_preserves_original_bytes`：1通过，验证原图字节、替换保存、失败时原目录内文件不变且无临时残留。测试未删除或弱化。
- Mac `cargo build --locked --manifest-path apps/desktop/Cargo.toml`、带现有LLVM PATH的Windows x64 MSVC完整应用 `cargo check --locked` 和 `git diff --check` 通过。前一次按original_image筛选运行得到0条，未把该次当验证；随后改为实际测试名称得到1通过。
