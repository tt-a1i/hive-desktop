# 跨后端文本接续与独立代码快照

2026-11-15。本批实现保留原会话，另建固定目标配置的新会话及私有工作树，不能理解为把厂商原生会话直接转换到另一后端。跟踪于 [#53](https://github.com/tt-a1i/hive-desktop/issues/53)，完整产品目标 #39 保持开放。本记录的最终包、界面和平台结果在本轮验收后补齐；未完成项不按通过计算。

## 可用范围和身份

源可以是内置 Pi、外部 Pi、Codex、Claude 或 ACP 已保存的可读历史。历史按权威持久条目 ID 选择；不会根据展示文本或位置猜测身份。快照保留事实正文、原会话及 profile revision、原执行目录和覆盖范围；缺页、截取、附件引用及未检查的原生新变化均明确列出。文本不能代替图片、音频或文件二进制迁移，也不重放历史工具、审批、派单或消费凭据。

第一片只接受可信且仍存在的原成员身份、已停止并且没有待发输入或未结协作责任的来源。只停止进程不代表责任已清。Hive 的只读同事务快照核对派单、未送达汇报、消息、问题及 controller 回执；应用另核对持久队列、原生消费收据和运行状态。未知、缺失、正在关闭或读取失败均不当作零责任。

目标使用用户选择的已保存 profile revision，与来源保留同一原成员身份；创建时不改变原绑定，也不复制原生 thread/session ID。首次明确普通输入才走正常激活。模型不从来源继承，不为了展示目标配置启动目录探测；未指定时采用目标原生默认，尚未探测的可用性不会显示为已确认。Pi 缺少默认模型时保留待交付资料及草稿，通过显式刷新、实际目录选择后继续；不自动登录或改全局配置。

## 代码与交付

可明确选择当前代码或来源已有检查点，预览冻结代码版本、历史范围与遗漏 hash。当前快照分别保留 HEAD、索引和非忽略工作文件；目标在新私有工作树物化，来源文件与索引保持。历史工具及报告的路径仍指向其原会话，不按新目录重解释。

预览、创建和被动冷打开不启动 Agent。持久操作记录及固定 request ID 支持响应丢失后查询、恢复同一 child，不能靠再次新建掩盖失败。首次用户输入的上下文预约与队列相连，只有目标自己的原生持久收据能证明已消费。已发送但结果未知时不自动重放；本地扩展处理了输入也不能冒充原生模型收到历史。

本片不迁移进行中派单，不原地改变旧会话后端，不实现完整图片迁移或共享写目录。源码可连接五类目标，不等于五家账号、模型与平台都已实际验收。Claude/Antigravity 不做账号或真实模型验收，Pi 登录失败不重试。

## 已有验证与待收尾

真实 Git/Hive 加受控原生协议已覆盖五类目标创建/被动冷开零 CLI、同 Worker 的 Codex 来源到 ACP 目标、HEAD/索引/工作文件独立物化、源停用后的离线读取、操作日志/索引/物化失败恢复、不确定投递及消费收据写入失败。真实 Pi SDK 本地模型夹具没有外部模型请求；扩展 handled 但未原生消费时保留未知状态。

独立审查发现首条已预约输入撤回后，后续排队输入可能丢失历史，现已补转移和冷修复，验证后续输入准确承接且不重复注入；首条编辑成 slash 在执行前拒绝。源码原生 UI 已通过 106 项 Rust 检查（1 项明确忽略的子进程 fixture），并修复延迟元数据查询越到被动目标的问题。组合包与真实窗口仍待本轮最终验收。
