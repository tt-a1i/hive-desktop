# 阅读体验开发包与文件预览提示

文件已成功预览、随后被删除时，“在文件管理器中显示”的路径校验会失败。原界面把所有错误统一包成“重新读取失败”，把定位失败说成了读取失败。本轮直接显示实际错误，并在仍有上次成功内容时独立说明，读取中也标明保留的是上次内容。不改变文件读取、路径校验、缓存内容或系统定位行为。

真实 GPUI / Hive / Pi 历史夹具依次读取、修改、删除、尝试定位、重新读取及恢复真实磁盘文件。浅色常规、浅色 760px 与深色 760px 验证缓存原文保留、恢复及原有键盘/关闭操作，另检查定位失败截图的提示。定位时文件已不存在，原有校验在调用系统文件管理器之前拒绝；没有实际唤起 Finder，没有厂商模型请求或用户剪贴板操作。夹具与证据位于 `.artifacts/file-preview-errors/`。

本次只改提示布局，以生产 Mac 构建、完整 Windows MSVC 默认功能类型检查、原生走查及解压后的包检查为验证范围；未新增 UI 单测，也未重复 Rust/Node 全量测试。最近的 23 项 Rust 检查及实际 Diff/查找证据分别记录在对应批次，不能当作本批重新运行。

## Mac arm64 开发包

`.artifacts/hive-desktop-macos-arm64-reading.zip` 包含工具与产物预览、只读合并/并排 Diff、补丁/错误查找和当前提示修复。复用已验证的 file-preview 冻结依赖包，核对原 ZIP 哈希、104 个 runtime 产物，并检查自该基线以来 runtime 源码/锁文件/补丁未改。更新生产 Rust 二进制后生成新 ZIP，再单独解压运行 `scripts/check-package.mjs` 与 `scripts/check-desktop-startup.mjs`，收据保存同一证据目录。
