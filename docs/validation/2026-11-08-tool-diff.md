# 工具记录的只读 Diff

## 使用变化与来源

工具编辑此前只能查看 JSON 和输出，定位少量改动需要逐段对比参数。现在展开 Edit/edit/MultiEdit 或 Codex fileChange 后可打开“查看改动”，用行号、增删背景与行内高亮阅读，切换合并/并排视图、跳转上一处/下一处、查看及复制原始补丁。小改动按内容估计高度，大改动使用受限高度与虚拟列表。

参考 Cindy 固定提交 `4fd670b72af9d060785e29c553a14b6794dfe8eb` 的 ToolCallCard / DiffView：Edit 的 old_string/new_string 对比、明确的增删层次和大内容虚拟化。复用已安装 gpui-kit 0.9.0 的 Diff/DiffState/DiffFile，实现读取、选择、折叠、软换行及原生键盘导航；没有重写 Diff 渲染器或修改 vendor。生成片段差异使用现有依赖图已包含的 similar 2.7.0，增加一个显式直接引用，未引入新版本或额外 crate。

## 数据语义

- 内置/外部 Pi：保留原生工具结果 details.patch；实时 tool_end 与持久历史通过同一保留入口。优先展示实际返回补丁，不以调用参数覆盖它。缺少对应调用参数时，只要仍有实际 patch，入口也保留；已用原生会话窗口检查。
- Claude Edit/MultiEdit 与没有实际 patch 的 Pi Edit：仅依据原生 oldText/newText、old_string/new_string 或 edits 数组生成请求片段。显示“工具请求的改动片段；行号从片段起点计算，不代表编辑已成功”，同时显示原工具状态；失败请求不会被展示成执行成功。
- 多段编辑分别编号，不假装已拼成完整文件；原生 Pi 返回完整 patch 时不做片段重建。
- Codex fileChange：按原生 kind 区分 add/delete 的文件全文和 update 的补丁。无文件头的更新补全原始/移动后路径，新增/删除使用 /dev/null；空新增文件仍保留文件状态。已有完整 patch 原文保留，不重复封装。
- 生成文件头时对路径引用编码，测试中文、空格、Tab 和引号；不允许路径换行成为额外补丁头。
- 本项不读取磁盘文件、不应用补丁、不撤销编辑。上轮“文件预览”继续查看当前磁盘，两种入口含义独立。
- 非法补丁显示错误并保留原始文本，不静默丢弃；没有文本差异时明确提示。部分可解析时仍保留整份原始补丁和错误提示。
- 差异计算与解析在后台执行，similar 计算设 500ms 期限，期限内不能取得最简差异时仍由库返回有效对比；不宣称所有结果均为最小编辑序列。

## 实际验证

`cargo test --locked --manifest-path apps/desktop/Cargo.toml`：23 通过、1 忽略。新增两个数据行为检查，覆盖原始补丁逐字优先、特殊路径、多段片段、新增/删除/移动、无末尾换行、无差异、空新增文件及非法补丁原文保留。未新增 UI 单测，未改 Node 协议、Hive 业务、SQLite 或权限规则，因此没有重复无关 Node 全量 suite。

真实 Pi SDK 1.4 Edit 工具在临时项目改写中文文件，核对写入结果和返回 patch，再写入真实原生会话；随后修改磁盘为不同内容，证明打开的 Diff 仍来自历史 patch。没有厂商推理。Claude 风格失败编辑和 MultiEdit、Codex add/delete/move/千行新增及非法 patch 是明确预置的原生记录夹具，不是原始 CLI 的本轮工具执行证明。

常规浅色、760px 浅色及 760px 深色 GPUI 窗口检查实际按钮鼠标事件、合并/并排切换、请求来源提示、多片段、千行虚拟 Diff End 到末尾、Cmd-A 选中当前文件完整原文、原始补丁和 Escape。全选按 Diff 组件的当前文件/侧语义验证，不冒充跨文件全选；复制整份补丁另有独立按钮，但未读写用户系统剪贴板做复制验收。额外使用实际生产事件处理入口的合成 ToolStart/ToolEnd 检查实时 patch 保留，不冒充真实流式厂商事件。

走查复现并修复：Diff 获得键盘焦点后切到原始文本，原焦点节点被隐藏，Escape 未到达对话框。现在保留独立原始文本焦点，切换时显式移交焦点；实际长 Diff 到原始文本、Tab/翻页、Escape 流程验证。失败校准日志、脚本、截图及收据保存在 `.artifacts/tool-diff/`。
