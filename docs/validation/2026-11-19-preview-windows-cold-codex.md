# HTML 预览窗口复用与 Codex 冷历史

## HTML 预览

用前一版解包应用打开已删除会话工作树的报告快照。预览里的计数器加到 1 后，关闭主窗口里的文件详情，再从报告中打开同一产物。基线出现两个同名 WebView 窗口，一个计数器为 1，另一个为 0。

窗口现在保存产物来源。桌面用工作区、路径、派单、来源成员及来源会话匹配现有窗口，并在读快照前和建窗前各检查一次。文件详情可以独立关闭。关闭预览本身后，下次打开会重新读取快照。[桌面实现](../../apps/desktop/src/html_preview.rs) · [文件详情入口](../../apps/desktop/src/file_viewer.rs)

新包用同一份隔离数据复验。重开详情后只有一个预览，计数器保留为 1。关闭该预览后再打开，计数器从 0 开始。含首次打开和关闭后的重新打开在内，快照请求由三次降为两次。最后保留预览窗口并关闭主窗口，桌面收到后台关闭确认、进程以 0 退出，记录的 Node 子进程消失。此项用窗口计数验证资源归属，没有测量 WebView 的 RSS。

## 只读 Codex 历史

只读冷打开现在只读和解析一次展示日志。完整性由同一份读取结果判断。测试覆盖完整日志、搜索索引缺失、含空项、重复消息 ID，以及展示日志文件缺失。索引有问题时仍显示可读正文和原消息 ID，并提示可能不完整。日志缺失时显示读失败原因。测试核对原文件未改写、未启动该 Codex 会话。基线解包应用中的 Node 在索引缺失时错误返回了无警告的历史。同一回归在新包内通过。[冷快照](../../packages/runtime/src/chats.ts) · [投影](../../packages/runtime/src/agents/codex-projection.ts) · [回归](../../packages/runtime/checks/historical-session-identity.ts)

隔离探测使用 macOS arm64、Node 22.23.3 及同一份 62,202,333 字节、2,500 条消息的合成日志。对照在同一生产投影前额外执行旧冷路径的第二次读取和解析，两组各跑三个独立进程。读取次数从 2 次降到 1 次，峰值 RSS 中位数从 450.6 MiB 降到 326.5 MiB，读取及投影时间中位数从 163 ms 降到 92 ms。数据适用于该 Node 投影探测。
