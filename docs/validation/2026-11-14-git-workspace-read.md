# Git 状态与文件差异：只读阶段

日期：2026-11-14。范围来自 [#43](https://github.com/tt-a1i/hive-desktop/issues/43)，属于功能补齐总任务 [#39](https://github.com/tt-a1i/hive-desktop/issues/39)。本阶段提供实际仓库的状态和文件比较；提交、推送及 PR 仍未实现，不能据此关闭 #43。没有继续视觉样式改造。

## 可用行为

桌面原有分支入口可以打开 Git 状态。后台从 Hive 工作区取得权威项目路径，不接受客户端指定任意目录或 Git 程序。状态区分项目根、仓库根、仓库内项目范围、分支、分离 HEAD、空仓库与链接工作树，并显示实际暂存/未暂存/未跟踪路径。结果在项目范围内分页。

选择文件可以比较 HEAD 到索引、索引到工作区，以及 HEAD 到工作区。重命名保留各比较侧的实际路径，未改内容的重命名明确显示无文本差异。二进制、符号链接、模式与子模块指针以对应元数据表示；冲突保留三个索引阶段，不把冲突阶段伪装为合并补丁。刷新和异步读取均绑定原工作区及后台连接，迟到结果不会替换另一项目的状态。

差异使用对象与磁盘的原始字节，不运行外部 diff、textconv、clean/smudge、项目 hook 或按需对象拉取。状态使用实际索引及隔离的临时 Git 配置，避免并发属性变化启动内容过滤程序；不改写真实索引或用户全局配置。只有实际应用于已跟踪文件的外部 clean/process 过滤器会阻止状态读取，未使用的全局 LFS 等驱动不会误阻断。原始字节差异仍可读取。

## 验证

- 运行时类型检查与编译通过；`check:git-workspace` 使用临时真实 Git 仓库，并通过真实 Hive 工作区验证 RPC 路径绑定及错误返回。
- 真实 Git 夹具覆盖三种比较、相同内容及修改后的重命名、空格/中文/换行/前导短横线路径、删除、二进制、符号链接、冲突、空仓库、分离 HEAD、链接工作树、项目子目录及跨范围重命名。
- 实际 split index、sparse index、SHA-256 仓库与忽略/属性规则通过；读取前后的真实索引字节保持。暂存子模块指针变化在已检出旧/新提交、内部脏文件及缺失检出时均保留，未扫描子模块内部内容。
- helper 哨兵覆盖 hook、fsmonitor、外部 diff/textconv/filter 和缺失对象自动获取，未执行这些程序。两组在属性检查后才改变属性或新增过滤驱动的真实竞态被安全拒绝；独立审查重新运行相关夹具后未发现进一步可操作缺陷。
- 原生 Git 响应解析、重命名两侧路径及旧响应兼容的三项定向 Rust 检查通过；macOS 和 x64 MSVC 检查通过。后者不等于 Windows 原生交互验收。

macOS 使用独立 `Hive Functional QA.app`、真实 Git 项目及受控 Codex 协议对端，未调用模型、未操作用户安装实例。实际走查了五条变更、中文路径、普通文件的三种比较、新文件、二进制元数据、磁盘修改后的刷新，以及退出浮层后草稿和两个暂停投递保持。重命名复验直接确认暂存比较旧路径到新路径、未暂存比较新路径到新路径，两者均没有文本差异。HEAD 到工作区的原路径及相同内容已直接确认；目标路径因图形捕获错误未直接读全，该字段由后台真实 Git 断言和共用渲染路径覆盖，不冒称完整视觉确认。

独立实例已请求正常退出，随后按专有应用及数据路径检查，没有该测试实例或其后台进程。原始原生日志及仓库种子在 `.artifacts/functional-parity/ui-qa/native-git.log` 与 `git-seed.json`。

## 交付边界

这些改动目前属于源码和调试实例，未进入当前 `837abd1` ZIP/DMG。Git 专项尚未在 Windows 执行；已有 Windows 便携包也不包含本阶段。默认状态页为 100 项，最多 500 项；状态输出、索引、文件和补丁都有有界限制，超限或并发变化明确报错。子模块内部变更、远端领先/落后、暂存和撤销暂存、提交、推送、PR、会话工作树及代码检查点分别继续实施。
