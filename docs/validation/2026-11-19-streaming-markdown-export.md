# Markdown 导出的内存使用

导出使用打开窗口时取得的固定会话快照。预览在 10,000 个 Unicode 字符处停止生成。保存时按记录写入临时文件，完成后原子替换目标。复制时在后台线程生成完整 Markdown，之后交给系统剪贴板。

保存面板等待用户选择路径时，程序持有共享快照和导出选项。导出功能只在复制时需要完整的 Markdown 字符串。编辑中的会话和导出窗口的固定快照仍各自持有显示正文。

## macOS 原生验收

对照包内的桌面程序来自 `1b3c069`，修复版来自 `c7e0ce5`。两版复用同一份运行时和隔离会话，共 1,801 条可显示记录。每次等长会话或导出预览稳定后取桌面进程 RSS 五次，报告中位数。

| 窗口状态 | 对照包 | 修复版 |
| --- | ---: | ---: |
| 长会话已加载 | 219.0 MiB | 221.1 MiB |
| 导出预览已打开，包含工具过程 | 267.2 MiB | 242.5 MiB |
| 打开预览后的增量 | 48.2 MiB | 21.4 MiB |

两版通过原生保存面板导出同一会话。两个文件各 22,421,463 字节且逐字节一致，包含 1,798 条长正文、首尾消息、工具输入、最终输出和补丁。短会话通过新版窗口复制，再粘到隔离草稿，核对了标题和 Unicode 正文。测试草稿已清除，两版均正常退出，后台确认关闭，记录的桌面和后台进程均退出。

新版优化包和 ZIP 解包均通过严格签名验证。ZIP 内 28,956 个文件、29 个链接和 2,709 个目录与打包目录一致。从最终 ZIP 解包后，56 项功能回归、Codex 传输和生命周期回归，以及 Node、PTY、Hive HTTP/SQLite 与退出冒烟均通过。Rust 测试 122 项通过，1 项子进程入口按设计忽略，覆盖 Unicode 预览边界和失败写入保留原文件。Windows x86_64 MSVC 交叉检查通过。RSS 数据来自本次 macOS 隔离会话，Windows 的原生内存尚待实测。

过程日志、RSS 样本、导出、ZIP 校验和独立收据位于 `.artifacts/streaming-export-kSOLII/`。运行使用离线历史，没有发起新的模型请求或发布。
