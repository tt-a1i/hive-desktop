# 日常工作流程与首次打开

本轮从 Hive Desktop 主线 `5e7aeb6` 开始。Hive 权威仓库主线核对到 `18861b8`，桌面仍使用锁定的 Hive 2.2.1。范围记录在 [#54](https://github.com/tt-a1i/hive-desktop/issues/54)。

| 场景 | 使用入口与行为 |
| --- | --- |
| 首次打开 | 没有既有工作区时显示欢迎页。可检查本机 Agent、前往对应设置、手选文件夹，或主动查找 Codex、Claude Code 与 Pi 最近使用的项目文件夹。用户确认后添加路径。可先进入工作区，之后从「设置 → 关于」重开。 [T3 Code 欢迎页](https://github.com/pingdotgg/t3code/blob/9cc4018c75ff4c61be8e86a6391d49a6c2d79830/docs/user/welcome-page.md) |
| 打开方式 | 项目菜单和「设置 → 通用」共用本机应用列表。显示已发现应用及系统图标，包括常见编辑器、IDE、终端与文件管理器。Xcode 打开项目、工作区或 Swift Package。 |
| 历史派单和成员收件箱 | 从派单详情或时间线分屏打开派单记录中的原始成员会话。缺少历史来源时，可用单独入口打开当前成员会话。协作页集中显示待答问题、失败投递、汇报及未读成员会话。可在本次应用运行期间暂缓指定协作消息或派单。 |
| Diff 评审 | 在差异行号区选择新增或删除行，再添加评论。现有草稿保留，附入所选改动、原始或修改后路径和行号。 |
| PR 评审 | 在 Git 远端面板输入 GitHub PR 地址或编号。可在干净的当前检出中评审，或创建独立工作树。会话草稿附 PR 链接及核对过的基准和目标提交。 |
| 旧消息 | 搜索结果以有界窗口打开原始消息。可继续加载更早或较新的页，也可直接回到最新消息。 |
| 终端选区 | 在终端选中文字后，从右键菜单将其加入当前聊天草稿，发送仍由用户触发。 |
| 文件浏览 | 从项目或聊天工具栏打开文件浏览器。目录树、文件名搜索、正文搜索及文本预览使用对应项目或会话执行目录。 |

## 验证

- TypeScript 检查、运行时构建与团队回归套件通过。首个旧消息页在 10,000 条历史的夹具中遵守页长限制。生产 JSONL 夹具覆盖双向页、活动回合、排队输入和旧视图拒绝。
- 派单来源测试覆盖成员切换会话和后台冷恢复。收件箱使用真实 Hive HTTP、SQLite 和团队消息检查新增问题及显式答复。项目文件检查覆盖同一路径在项目与两个工作树中的独立内容，以及文本搜索、预览和取消。
- macOS 原生 Diff 窗口将选中的删除行和新增行写入既有草稿，并保留在本机草稿文件。Finder 与 Ghostty 在带空格、符号和中文的临时目录中启动，Ghostty 的工作目录已独立核对。
- Windows x64 目标通过 MSVC 交叉类型检查。Windows 原生窗口和该平台安装包验收待执行。

以上运行时与桌面验证使用隔离数据或受控 Agent 对端。
