# 独立会话工作树清理

会话操作菜单提供「清理独立工作树」。预览展示实际检出目录、分支和提交。确认后重新核对归属、文件状态和使用状态，再执行普通 Git 工作树移除。原 Git 分支、会话 ID、历史与草稿保留，原会话以只读方式打开。跨会话搜索和从原派单打开会话仍使用原身份。

退出中的会话、在途脚本或终端、当前协作目标、未结派单、被其他工作区使用的目录、已锁定的工作树和无法完整核对的文件都会阻止清理。未跟踪、被忽略或带有隐藏工作区修改标记的文件也会阻止清理。独立分支有新增提交时，从配置的远端实查分支及其祖先关系。没有足够的已推送证据时保留整个检出。本操作保留本地和远端分支。

## 实际验证

- 真实 Git 测试覆盖替换目录、锁、未跟踪和忽略文件、`assume-unchanged`、未推送提交。通过实际 bare 仓库验证推送后的清理，并验证远端分支删除后旧的本地跟踪记录不能使旧预览生效。
- 生产 JSONL 使用真实 Hive SQLite、Git、持久 Pi 历史和终端进程。过期确认、活跃终端和确认前新写入的文件均被拒绝。正常清理后分支的提交保持一致。冷启动会话为只读，成员历史仍保留原身份，正文搜索仍能定位该会话。另验证历史身份及 Git push、PR 和退出等待的既有契约。PR 回归使用受控 `gh` 对端。
- macOS 优化包 `f4e654e` 从实际会话菜单打开预览。含本地文件时，辅助功能可读取拒绝原因，确认按钮不可用。移走并保全测试文件后，辅助功能可读取实际路径、分支和提交，确认后窗口显示清理成功。独立核对 Git 注册、原分支、原项目、第二棵工作树和原始对话文件。关闭再启动，从侧栏用正文搜索打开同一份只读历史。隔离运行观察到的桌面和后台进程均正常退出，没有模型调用。
- 最终本地 ZIP 解包验签通过，逐项比对应用树一致。解包后通过真实 PTY、Hive HTTP/SQLite 与退出冒烟。四项包内回归使用与最终 ZIP 字节相同的 Node 和后端运行时。Rust 测试 122 项通过，1 项子进程入口按设计忽略。Windows MSVC 交叉检查通过，当前流程仍待 Windows 原生验收。

包、日志和收据在 `.artifacts/worktree-removal-vhS11T/`。验证工具在观察退出后额外打开了一次测试包，默认桌面数据库的修改时间随之更新。该进程已关闭，这次额外打开没有执行模型、账号或设置操作。本轮没有发布或替换已安装应用。
