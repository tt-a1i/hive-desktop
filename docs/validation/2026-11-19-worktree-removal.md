# 独立会话工作树清理

会话操作菜单提供「清理独立工作树」。预览展示实际检出目录、分支和提交。确认后重新核对归属、文件状态和使用状态，再执行普通 Git 工作树移除。原 Git 分支、会话 ID、历史与草稿保留，原会话以只读方式打开。跨会话搜索和从原派单打开会话仍使用原身份。

退出中的会话、在途脚本或终端、当前协作目标、未结派单、被其他工作区使用的目录、已锁定的工作树和无法完整核对的文件都会阻止清理。未跟踪、被忽略或带有隐藏工作区修改标记的文件也会阻止清理。独立分支有新增提交时，从配置的远端实查分支及其祖先关系。没有足够的已推送证据时保留整个检出。本操作保留本地和远端分支。

## 实际验证

- 真实 Git 测试覆盖替换目录、锁、未跟踪和忽略文件、`assume-unchanged`、未推送提交。通过实际 bare 仓库验证推送后的清理，并验证远端分支删除后旧的本地跟踪记录不能使旧预览生效。
- 生产 JSONL 使用真实 Hive SQLite、Git、持久 Pi 历史和终端进程。过期确认、活跃终端和确认前新写入的文件均被拒绝。正常清理后分支的提交保持一致。冷启动会话为只读，成员历史仍保留原身份，正文搜索仍能定位该会话。另验证历史身份及 Git push、PR 和退出等待的既有契约。PR 回归使用受控 `gh` 对端。
- macOS 优化包 `f4e654e` 从实际会话菜单打开预览。含本地文件时，辅助功能可读取拒绝原因，确认按钮不可用。移走并保全测试文件后，辅助功能可读取实际路径、分支和提交，确认后窗口显示清理成功。独立核对 Git 注册、原分支、原项目、第二棵工作树和原始对话文件。关闭再启动，从侧栏用正文搜索打开同一份只读历史。隔离运行观察到的桌面和后台进程均正常退出，没有模型调用。
- 最终本地 ZIP 解包验签通过，逐项比对应用树一致。解包后通过真实 PTY、Hive HTTP/SQLite 与退出冒烟。四项包内回归使用与最终 ZIP 字节相同的 Node 和后端运行时。Rust 测试 122 项通过，1 项子进程入口按设计忽略。Windows MSVC 交叉检查通过，当前流程仍待 Windows 原生验收。

包、日志和收据在 `.artifacts/worktree-removal-vhS11T/`。验证工具在观察退出后额外打开了一次测试包，默认桌面数据库的修改时间随之更新。该进程已关闭，这次额外打开没有执行模型、账号或设置操作。本轮没有发布或替换已安装应用。

## 清理完成后收据中断

GPT-6.2 Sol 在真实临时 Git 仓库复现了清理收据写入失败。此前 Git 已移除检出，下一次从原派单打开会话却会报告来源不匹配。

现在 Hive 在删除前先记录用户确认的提交和原 Git 元数据目录的文件系统身份。关闭当前句柄后重新验证远端，再在写入意图后检查工作树归属、分支、提交和文件状态。冷打开时，仅在原目录和 Git 登记确已消失、原仓库与保留分支仍可核对时补写收据。仅用 Git 在外部移除的工作树保留原先的来源失效保护。外部 Git 与 Hive 之间没有共享的原子删除锁。

真实 Git 回归覆盖意图写入失败时保留检出、Git 删除后的收据写入失败、新的未推送状态、旧分支提交变化、同路径替换 Git 元数据目录，以及意图落盘时同路径检出另一分支。生产 JSONL 从原派单进入并确认同一会话和只读历史。正文搜索也仍能找到原会话，执行入口继续拒绝该已移除工作树。

macOS 从签名 ZIP 解包后，在原生窗口确认移除，注入收据写入失败并核对界面提示。退出重开后原会话恢复为只读，Git 分支和历史文件保持一致。旁边的工作树与原项目保持完整。两次退出均有后台确认，观察到的进程全部结束。只收到一次工作树删除请求，无模型请求。

源码为 `6f2f778`。包复用 `c8ff5bf` 的原生程序和同一份 Node，只更新工作树运行时代码及其源映射。完整归档清单、严格验签、工作树专项和包内 Node、PTY、Hive HTTP/SQLite 与正常退出均通过。当前版本的 Windows 原生窗口仍待验收。本轮没有发布或替换已安装应用。

## 推送到不同名分支后的清理

GPT-6.2 Sol 在真实 bare 仓库和生产 JSONL 中复现了旧版错误。独立工作树推到不同名的远端分支后，清理仍提示需要推送。`c08fbc9` 保存最近一次由 Hive 验证成功的目标及提交，清理时按当前远端和分支重新验证。上游配置保持由用户管理。已配置的上游及唯一同名跟踪分支仍可独立验证。远端改址、目标分支删除或本地新增提交时，如果没有其他证据确认当前提交已发布，继续保留检出。远端推送已确认但本地记录写入失败时，Hive 显示两项实际结果。

旧包和解包新版从原生 Git 面板推送到本地 bare 仓库的 `review/desktop-checkout`。独立 Git 命令确认远端提交和工作树文件相同，且未设置上游。冷重开后，旧包拒绝清理。新版可预览并确认清理本地检出，两端分支保留。再次冷重开仍可读原会话，历史字节、原项目和另一棵独立工作树保持一致。测试窗口均收到后台关闭确认。

证据位于 `.artifacts/exact-script-recovery-IX8tP2/`，旧包和新版原生收据分别为 `git-baseline-gAwOws/renamed-push-receipt.json`、`git-candidate-NTbeQx/renamed-push-receipt.json`。额外生产 JSONL 回归在 `.artifacts/worktree-push-receipt-X0TQXo/after.json`。当前 Windows 版本通过 MSVC 交叉检查，原生操作待验。本批使用本地包和本地 bare 仓库。
