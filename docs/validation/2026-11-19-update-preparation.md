# 更新包安装前准备

桌面后台保存已下载归档及其签名清单。冷重开后，可以通过生产 JSONL 接口用已缓存的清单离线核验。解包到私有临时目录前重新计算归档长度与 SHA-256。解包逐文件写入并检查路径冲突、特殊文件、文件总数及内部链接。准备完成时校验桌面程序、内置 Node、后台入口、平台、架构和选定版本。macOS 另核对 `Info.plist` 的启动文件、应用标识和版本。

首个实际 Mac `ditto` 归档有 66,075 个物理条目，ZIP 目录头报告 539 个条目，准备流程未成功。改用打包器的 `--update-archive` 后，真实归档有 31,683 个条目及 28,974 个文件和链接。隔离旧版本策略使用 `0.0.9`，测试下载并核验真实 `0.1.0` 包的 162,964,634 字节。关闭回环服务和原后台，重新启动包内 Node，生产 RPC 离线完成准备。实际运行解包后的原生身份查询，验证为 `darwin/arm64` 的 `0.1.0`。证据位于 `.artifacts/update-preparation-mac-jnMOUc/receipt-canonical.json`。测试截止到准备阶段，应用替换和失败回退仍待实施。

源码回归覆盖同尺寸篡改、错误版本、路径越界链接及准备失败清理。`pnpm check`、运行时构建和 Mac Rust 构建通过，Windows Rust 交叉编译通过。准备后的目录通过包内 Node、真实 PTY 和 Hive HTTP/SQLite 冒烟，没有调用模型。Rust 一次只运行一个编译作业。

Windows 上一轮基线生成了 Release 便携包，并通过 47 项包内功能检查。原生窗口测试运行到最终持久化检查，旧断言把新增外观字段误判为错误。测试现预置非默认代码字号和换行，并分别断言主题切换结果和这两项设置的保留。[基线 CI](https://github.com/tt-a1i/hive-desktop/actions/runs/44334015186)
