## 本地 Git

在已实现的[只读状态与差异](2026-11-14-git-workspace-read.md)上增加单文件暂存、撤销暂存和完整索引提交。预览会列出实际受影响路径；已知改名同时处理两侧，拒绝跨项目范围的隐式操作。写入校验预览版本，取得真实索引锁，在准备索引中执行，再原子安装；失败不把旧索引回滚覆盖另一工具的写入。撤销暂存只改索引，文件被磁盘目录替换时仍保留目录内容。

提交预览包含整个仓库的暂存文件和补丁；项目子目录外的已暂存文件需要显式确认。使用原生 Git commit，保留 hooks、身份与签名配置，不自动暂存、amend、推送或跳过 hooks。hooks 可能修改索引、工作文件和提交说明。执行前校验与 Git 原生 ref 事务共同保护并发，未宣称原生进程初始化前不存在时间窗口。正在进行 merge/rebase/cherry-pick/revert 的仓库明确拒绝普通提交，这些流程仍待扩展。

提交结果分别报告是否已创建提交、实际 OID 与索引是否同步；提交已创建后的安装/刷新失败不能误报“未提交”。超时等情况下无法确认 HEAD 变化归属时返回 `unknown`，要求核对，禁止自动重试。关闭运行时会等待本次 Git 写操作结束，关闭中不接受新写操作。

真实 Git 夹具与独立审查覆盖：空仓库、链接工作树、split index、选中项保护、内容过滤器、改名/删除/二进制/Unicode、锁和并发写、原生 hooks 与 hook 失败、缺失身份、失败 signer、HEAD 并发推进、提交成功后的索引安装失败，以及超时进程组清理。Windows 写操作与 taskkill 分支尚未原生验证。实际 JSONL/Hive/Git 检查进一步核对了参数、陈旧版本拒绝、原生提交结果字段和会话工作树写入不改变团队根索引；POSIX 真实 hook 检查确认退出会等待提交。

macOS 独立 QA 实例真实完成了取消预览、暂存、撤销暂存、再次暂存、完整提交预览、故意 hook 拒绝、保留说明，以及修正测试 hook 后的成功提交。独立读取确认提交 `81bac42c20fb9ae35b2bbcfb61c9308c6f853991` 包含 notes 与改名，三个未跟踪文件仍未加入；聊天草稿和两个暂停投递保持。走查发现初次打开 Git 浮层同步读取正在更新的父界面会退出，改为延后读取后复验通过。实际成功二进制 SHA-256 为 `5e5caa51a42df192a3504bacba9120b8019a3d21162ea37ddcec2400086dff7c`。收据在 `.artifacts/functional-parity/ui-qa/git-{hook-rejection-verified,ui-commit-verified}.json`；退出后专有进程检查为空。推送和 PR 尚未提供，#43 保持开放。

## 快捷键

设置页可录制、停用、恢复会话搜索、当前对话查找和设置入口的快捷键。按当前平台校验文字编辑、系统及已注册组件快捷键冲突，原子保存私有文件；未知版本、损坏或写失败不静默覆盖原文件。保留默认离线操作，仅首次取得权威数据目录时应用保存配置，重连不重复注册。修改保存后明确重启生效，当前与待生效提示分开；不清空 GPUI 组件绑定。

七项定向检查、Mac 与 MSVC 检查通过。独立审查发现并修复了 Shift 标点释放顺序和归一化截图组合键问题。macOS 实际验证默认三个入口、录制期间阻止旧全局动作、重复组合/CmdC/CmdQ 拒绝、保存后的当前键保持、重启后新键生效/旧键失效、停用及恢复默认。普通草稿与暂停队列保持，稳定输入下 Undo/Redo 实际有效。不同物理释放顺序、窗口失活和真实输入法组合未直接验收，Windows 原生本功能尚未验收。日志在 `.artifacts/keybindings-*.log` 与 `functional-parity/ui-qa/native-keybindings.log`。

## 工作树与实际 Agent

按 [ADR 0002](../adr/0002-session-execution-directory.md)保留唯一 Hive 工作区和团队账本，为新会话持久化独立执行目录。四后端的装配采用该目录，团队工具仍按原工作区与成员身份处理任务。已有原生会话不通过改 cwd 原地迁移。私有创建意图与实际 Git 元数据所有权标记共同验证工作树；缺失、替换、基础提交不含项目子目录或无法确认所有权时失败，不能回落团队根。归档不删除代码。

真实 Git/Hive 检查覆盖两目录隔离、子目录/linked worktree、污染 Git 环境、路径尾随空白、创建和索引发布失败恢复、关闭时等待创建、未提交/未推送/使用中清理拒绝，以及工作树缺失时暂停队列字节保持且未启动后端。引用保存来源会话，源状态始终比较原目录；派单执行来源独立持久化，使同一成员换绑后历史产物不改指向新会话。产物解析在来源不明时明确拒绝；旧版本只在不存在隔离会话迹象时使用原项目根并告警。来源解析、并发发布与实际路径边界另有独立真实夹具通过。Mac 隔离窗口已验证：待处理报告和派单详情在成员换绑 B 后仍读取 A，B 的工具文件读取 B；重新读取能观察 A 后续修改，A 临时缺失时明确标注错误与上次成功内容，没有回退 B 或团队根，恢复后重新读取成功。真实 Hive 派单与报告为测试数据，B 工具历史明确为受控夹具；本轮未调用模型。历史会话导航另发现按当前成员绑定打开 B 的缺口，正在改为准确派单来源，并同时修复旧 Worker 会话继续时的身份推断。

四后端另有 `worktree-backend-cwd.ts` 装配检查通过：内置 Pi 使用真实 SDK 与会话 header，Codex/外部 Pi 使用真实受控协议子进程，Claude 经官方 SDK 及原生格式 transcript；实际 cwd、新建/恢复参数和冷读身份均正确，零厂商请求。Codex 的一次受控 turn 仅用于生成恢复身份，不算真实模型证据。缺失工作树的正文搜索只告警对应会话，仍保留其他标题结果。

真实验收脚本为 `packages/runtime/checks/worktree-native-codex.ts --live`，只用原生 Codex 0.169.0 与 `openai/gpt-6.1-terra`。首轮因测试未显式启动 user-managed 成员而超时，保留 `run-NGGHXj` 的失败；修正 setup 后新建独立轮 `run-sS0Q3m` 通过。一个工作区的主控与成员在两个工作树实际写入不同标记文件，独立字节核对通过，团队根没有这些文件；主控实际读取发生在权威 reported 时间之后。真实 seen=0 对应空任务消息 inbox，成员实际执行 messages 和显式 report。

实际原生回合为主控 3、成员 1；额外主控回合来自既有启动状态和报告转发，不宣称每角色一轮。完整关闭重开后 thread IDs、执行目录、队列、报告和账本身份保持，未增加 turn/start 或 turn/steer，专有 CLI 均关闭。成功收据与独立摘要在 `.artifacts/functional-parity/native-worktree/run-sS0Q3m/{receipt,verified-summary,cold-report-identity}.json`。这证明该装配下的真实协作；不把预绑定测试设置、后续确定性产物来源测试或构建当作工作树完整 GUI 交付。创建入口、会话终端与新包验证继续实施。Claude/Antigravity 不做账号或真实模型验收；Pi 登录未重试，全局账号和模型配置未改。


## 会话终端与待验收入口（2026-11-15）

复用 Hive 原有 shellRuntime、进程管理与 PTY/确认机制，为会话增加独立 Shell 身份及权威执行目录。桌面提供自动、工作区、当前会话三个选择；自动模式对工作树会话选择其自身目录，普通会话保持原工作区默认。切换会话或隐藏只断开视图，后台 Shell 继续运行，返回时恢复同一活跃 PTY 快照；完整后台退出后不承诺恢复已经结束的进程或滚屏。

真实本地 Git、Hive 与三个 PTY 验证了根/A/B 目录和同名文件隔离、输入与 ACK、断开重连快照、跨会话拒绝、单独停止和工作区整体退出清理。审查发现的“目录缺失后无法停止已断开的 Shell”和“spawn 成功后登记失败遗留进程”已修复，测试直接核对 PID 退出。来源失效时只保留准确登记的活跃 Shell 供停止，禁止新建或连接，也不回退根目录。最新收据为临时目录 `hive-session-terminals-k06In4/receipt.json`，这是 POSIX 实际 PTY 证据，不代表 Windows 会话终端验收。

工作树创建/失败反馈/待恢复入口及会话终端 UI 已通过 Mac/MSVC 源码检查，尚待本批真实窗口操作。独立 QA 使用二进制 `2ef1a0702d09ed80c5d79d54b84aa28ee6171869cc19784fc5f9a5978b56ee43` 和新部署依赖；Hive 2.2.1 patch `e323182b5ba38349f05409dba75f53d6aeba0bc1d8e4655234faf5eb48ccb1f9` 的 1,177 个包文件已逐个比对。准备操作时 Mac 锁屏，工具要求用户手动解锁；尚未实际点击本批新入口，不据构建或准备好的夹具宣称通过。旧 837abd1 开发包与用户安装实例均未替换。
