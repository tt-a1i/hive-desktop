# 工作区 Shell

桌面终端复用 Hive 的真实项目 Shell。隐藏视图保留进程，重连恢复屏幕，显式停止结束进程。Agent 主控和成员继续使用统一的结构化聊天。

macOS 原生开发包验证了从启动按钮直接输入、Return 执行、Tab、方向键、退格、Escape、Ctrl-C、中文粘贴以及 ANSI 颜色、光标查询与备用屏幕。原始 PTY 记录的“中文蜂巢”为 `e4b8ade69687e89c82e5b7a2`。系统输入法已观察到拼音组合，完整候选词提交、选择复制与 Windows 窗口验收仍待完成。没有模型调用。

在 `packages/runtime` 运行 `pnpm check:terminal` 会构建 sidecar 并执行五组检查。真实 Hive/SQLite/PTY 覆盖目录、调整尺寸、进程退出、资源回收、原始输入和恢复边界。单独的 WebSocket 对端验证 parser 消费前后 ACK 的顺序。Rust 终端组件六项检查和传输顺序三项检查也已通过。

## 隐藏后释放终端资源（2026-11-19）

显式隐藏工作区终端时，桌面释放本地滚动历史和解析器状态。后台继续运行同一个 Shell，重新连接时恢复屏幕和滚动历史。应用为终端注册一组 Tab 和 Shift+Tab 快捷键，重连时复用。

用 macOS arm64 优化包和真实 PTY 输出 9,000 行。隐藏后，桌面进程的存活堆分配由 45.2 MiB 降到 18.2 MiB，旧版在相同输入下由 45.5 MiB 降到 45.4 MiB。本次隐藏前后的进程 RSS 基本持平。重开后依据同一 Shell 运行 ID 核对了旧输出和隐藏期间的输出，原生按键分别交付 `09` 和 `1b5b5a`，停止操作结束了 Shell 进程。

开发包通过严格签名校验、8 项包内功能检查和真实 PTY、Hive HTTP/SQLite 验证。关闭原生窗口后，桌面进程以状态 0 退出，后台确认关闭并结束。131 项桌面 Rust 测试通过，1 项忽略。Windows 已交叉检查，当前修改的原生窗口复测仍待验。本次未调用模型。证据保留在 `.artifacts/resource-ownership-9RmUGE/`。
