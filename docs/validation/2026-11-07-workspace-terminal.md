# 工作区 Shell

桌面终端复用 Hive 的真实项目 Shell。隐藏视图保留进程，重连恢复屏幕，显式停止结束进程。Agent 主控和成员继续使用统一的结构化聊天。

macOS 原生开发包验证了从启动按钮直接输入、Return 执行、Tab、方向键、退格、Escape、Ctrl-C、中文粘贴以及 ANSI 颜色、光标查询与备用屏幕。原始 PTY 记录的“中文蜂巢”为 `e4b8ade69687e89c82e5b7a2`。系统输入法已观察到拼音组合，完整候选词提交、选择复制与 Windows 窗口验收仍待完成。没有模型调用。

在 `packages/runtime` 运行 `pnpm check:terminal` 会构建 sidecar 并执行五组检查。真实 Hive/SQLite/PTY 覆盖目录、调整尺寸、进程退出、资源回收、原始输入和恢复边界。单独的 WebSocket 对端验证 parser 消费前后 ACK 的顺序。Rust 终端组件六项检查和传输顺序三项检查也已通过。
