# 冷打开接续会话的待发消息与项目文件选择器

## 待发消息

- 用同一份本机 Git、Hive SQLite、上传记录和待发队列数据运行解包后的前后两个版本。基准 `72fbbbc` 显示两条待发消息，未提供编辑和撤回操作。新包 `b4dfbc0` 的原生窗口可以编辑第二条并撤回第一条。
- 编辑后读取持久队列，第二条消息的投递 ID 与附件上传 ID 仍与原记录一致。撤回第一条后，记录在队列里的上下文引用转移到第二条。打开、编辑、撤回和再次冷打开期间，受控 ACP 进程的协议记录逐字节一致。
- 第二次冷打开后，原生界面保留编辑后的正文和原附件。点击继续后，ACP 只收到一条普通用户消息，其中包含编辑后的正文和一次冻结上下文。原生界面的接续状态更新为 `consumed`。
- 运行时回归还覆盖过期编辑拒绝、带上下文的待发消息不接受斜杠命令，以及上下文引用写入失败后冷打开恢复。队列和接续套件均通过。

此轮允许直接编辑仍待首次交付上下文的已知接续会话。已尝试或结果不确定的上下文仍受恢复规则约束。普通 ACP 冷会话的待发队列操作仍需先激活。

## 项目文件选择器

独立工作树的 Git 索引保留 `folder-replaced-native/tracked.txt`，磁盘上同名目录已换成普通文件。原生引用文件对话框的空查询返回该普通文件和其他项目文件。失效的索引路径没有出现在结果中。源码回归另验证结构化引用和两个独立工作树里的引用冷恢复。

## 包与生命周期

- macOS ZIP 内二进制使用单任务 Rust release 构建。打包脚本验证官方 Node 的 SHA-256，应用原包与解包均通过本机严格签名验证。ZIP 解包清单的 28,956 个文件、29 个链接及 2,709 个目录与原包一致。ZIP SHA-256 为 `0e741f5e9cbde05318eabd03f20a48a88b686215368f503aed7373a652111118`。
- 正式便携包冒烟覆盖包内 Node、真实 PTY、Hive HTTP/SQLite 与关闭流程。本轮新版的两次原生进程均收到后台关闭确认后以 0 退出，其 Node 后台进程也已结束。Rust 122 项通过，1 项明确忽略。Windows MSVC 交叉检查通过。
- 本轮使用受控 ACP 对端，没有新模型调用、发布或安装替换。当前版本的 Windows 原生窗口及整包更新交接仍待验证。
