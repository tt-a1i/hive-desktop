# 成员职责查看、复制和搜索

任务 #10，属于完整桌面体验 #1。已有 Hive 成员接口返回 description，桌面 DTO 之前丢弃该字段，创建后的职责无法阅读。

## 行为与边界

成员卡片显示首个非空行摘要，支持展开/收起完整原文及复制，搜索包含职责正文。展开正文限制高度并可独立滚动，空职责显示“未设置职责说明”，不提供无内容的复制按钮。刷新和成员会话往返保持当前展开状态，切换工作区清除展开集合；重启后仍从真实 Hive 数据读取职责，展开状态不持久化。

沿用原有成员搜索和状态筛选，未改后端 API、成员运行状态、派单、认证或模型配置。现有 Hive PATCH 只支持名称/头像，因此本次没有伪造职责编辑入口；修改职责需要后续明确接口。

## 实际验证

- 使用真实 Hive HTTP/SQLite 创建的 Reviewer、Tester 和空职责成员，复用同一验证应用及现有包内 Node/runtime，没有复制新的生产依赖树。仅替换验证应用的原生程序。
- Mac 系统鼠标/键盘验证摘要、展开/收起、空提示、职责正文搜索 blocking issues 只命中 Reviewer、清除筛选、刷新及成员会话往返。约 1180 和 642 逻辑像素窗口验证可阅读，窄窗口滚动到最后成员并展开空提示通过。
- 点击复制后粘贴到 owned Tester 会话草稿，未发送；退出后逐字核对保存的草稿与 Hive 原始职责一致，包括换行。SHA256 为 `3b10507a60e9f7f0f2d46127f9fb0f33eed00a340570d2dc27368224273403cc`，完整重启也恢复该草稿。
- 滚动校准：本机 CUA 的 up 命令向后续行滚动，down 返回顶部；早先据 down 无变化误判列表不可滚动。已撤销为此尝试的 min_h_0 和内容容器改动，并在原布局的最终生产程序重新验证到底部及空提示，未为自动化方向问题改变产品语义。
- 中间 content-scroll 与最终 final 验证进程均正常零退出。一次 CUA 在退出后查询应用导致额外启动了无环境变量的窗口，该窗口提示缺失后台；关闭后重新绑定正确 owned 进程，不据此改生产代码。屏幕捕捉也曾失败/捕捉到系统切窗动画，之后聚焦窗口取得正常画面，未当作产品渲染缺陷。
- cargo check、生产 cargo build 和 git diff --check 通过。纯 UI 与现有字段反序列化补齐，不新增测试，不改/删现有测试，也不运行无关 runtime 全量检查。没有厂商推理请求；隔离模型配置仅 Terra。

日志、复制校验与最终收据位于 `.artifacts/member-responsibilities/`。本次验证为 Mac 源码原生应用，不冒认已更新开发 ZIP、Windows 原生或完整产品目标验收。
