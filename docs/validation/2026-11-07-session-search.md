# 跨项目会话查找

2026-11-07。

侧栏“搜索会话”和 macOS Cmd+K / Windows Ctrl+K 打开原生搜索对话框。当前匹配会话名称、当前成员名称、项目名和 Agent 后端，多个词同时匹配，结果按最近会话时间排序。支持方向键选择、Enter 打开、Escape 返回。搜索不改写项目的展开状态或导航位置，只有打开结果时才切换会话。

## 运行边界

搜索通过现有 Hive 工作区和团队元数据、桌面会话索引查找，不读取完整厂商聊天记录，不初始化待查找的 Agent。最多显示 100 个结果，同时显示完整命中数，输入更具体的名称可以找到初始 100 个结果以外的记录。

打开跨项目结果时，会把目标记录交给已有导航和会话加载入口；原项目及目标项目各自保留草稿。目标后端的打开错误由已有会话恢复界面处理。

## 实际验证

- `checks/session-search.ts` 使用真实 Hive HTTP/SQLite 工作区和持久索引。覆盖四后端、中文与 emoji、多个查询词、大小写、项目与后端筛选、空结果、非法查询、重启及 101 个匹配的结果限制。冷会话搜索前后记录相同，Agent 事件为零。
- 同一检查用原生内置 Pi 的 GPT-6.1 Terra 配置创建成员并改名，确认搜索使用当前成员名称。查找前后团队状态和 Agent 事件保持一致，未发起模型请求。
- `scripts/check-package.mjs` 使用便携包中的实际 JSONL RPC 验证四后端记录查找、中文后端别名和无匹配结果。
- macOS 原生窗口实际点击和键盘验证 Cmd+K、方向键、Enter、Escape。从 Beta 查找并打开 Alpha 的目标会话，没有被 Alpha 原先保存的另一个会话覆盖。往返后两个项目的不同草稿均保留。
- 从设置页的未保存路径打开搜索并取消，仍显示原路径草稿。过长查询显示错误，改为合法中文查询后恢复结果。当前中文成员名可以找到并打开对应成员会话。
- Windows 原生检查已增加成员查找、主控查找和成员草稿回读，GitHub 计费限制下尚未运行。

借鉴 Cindy 的会话查找交互。当前 Hive 提供跨项目名称查找，未实现聊天内容全文搜索或 Cindy 的模糊评分排序。完整产品目标仍需继续验证。
