# 项目内新建与折叠状态验证

日期：2026-11-08。范围：项目/会话导航交互，完整 UI/UX 目标继续开放。

## 场景与改动

同时使用多个项目时，原侧栏只有当前项目的新建入口；用户必须先选择项目再回到顶部。新增每个项目行的“+”菜单，可选择内置 Pi、Codex、外部 Pi、Claude Code，沿用原有聊天记录创建及打开流程。菜单捕获项目 ID；执行前核对连接、关闭状态、目标存在及未移除，避免同名项目混淆或过期菜单选项生效。

折叠项目原本隐藏所有子会话活动。现在显示最需要关注的一类及数量，悬停说明全部已知分类，点摘要展开；复用会话行的优先级：待回应、处理中、已暂停、未读。同一会话只计最高优先级，空项目不显示计数。折叠按钮补充辅助技术切换状态。

如果不做，跨项目新建仍需额外定位，折叠项目则看不到已知的子会话活动。改动不增加调度器或改变 Hive 协作语义。

参考固定的 Cindy ProjectNode 源码（`4fd670b72af9d060785e29c553a14b6794dfe8eb`），其项目头提供项目内创建入口和折叠活动提示。本轮只借鉴这两项，不宣称实现其完整归档、置顶或项目管理体验。
