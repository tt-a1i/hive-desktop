# 手动项目脚本与日志内存

关闭项目脚本页、切换设置区或更换执行目录时，桌面释放已读日志的原始字节、展示文本和滚动状态。迟到的页面响应不会把内容放回窗口。后台仍管理脚本与磁盘日志。返回页面可以从第一页重读同一运行。

翻页请求只保存运行 ID、偏移和上限。接收后校验来源，再追加到当前缓冲。替换已满的显示段时，最多复制末尾三个字节以保留跨页 UTF-8 字符。没有变化的页面刷新复用同一份展示文本。每页和每个显示段维持原有上限。

## macOS 原生验收

在独立 Git 仓库和本地签名开发包中，通过原生项目脚本页面选择已保存的脚本和执行位置。

- 在会话工作树运行脚本。工作树路径标记与 Git 及实际执行位置一致，项目根没有这份标记。运行成功，PTY 日志共 161,551 字节，包含开头、结尾和 1,700 行测试内容。
- 在窗口连续读取两页，再切到另一个设置区。返回后，原运行仍选中且显示日志已清空，手动重读可再次看到原日志的开头。
- 在项目根启动有子进程的后台脚本。关闭设置后用系统进程表确认父进程与子进程仍运行。重开设置并显式停止，界面显示取消与退出信号 15，独立核对两个进程均退出。
- 正常退出并冷启动，两个运行记录仍在，原始日志可读。没有重跑脚本或调用模型，两次应用退出均有后台确认。

运行时项目脚本专项、117 项 Rust 测试和包内 Node、PTY、Hive HTTP/SQLite 及退出冒烟通过。Windows x86_64 MSVC 交叉检查通过，本批窗口与日志释放待 Windows 原生复验。没有发布。

本地证据位于 `.artifacts/manual-project-scripts-PVP5DV/`，含 `receipt.json`、严格签名验证通过的本地包、实际日志与两次退出记录。
