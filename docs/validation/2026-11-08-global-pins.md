# 跨项目置顶与导航验证

日期：2026-11-08。范围：跨项目常用会话入口及统一导航，不代表完整 Cindy 体验交付。

## 场景及结果

项目内置顶仍要求先展开对应项目；常用主控或成员分散在多个项目时，用户要反复展开和搜索。新增独立的全局置顶区，工作区列表收起或该项目会话尚未加载也可直接打开原会话。每项显示标题、项目归属、会话活动，支持独立收起、刷新和取消置顶。同名项目显示目录末级和父目录，提示中保留完整路径。若不做，置顶在跨项目使用时仍无法减少这些定位步骤。

以已取得的 Cindy 固定快照 `4fd670b72af9d060785e29c553a14b6794dfe8eb` 的独立置顶区及项目导航为参考。首版保留项目内同一条会话，两个区域使用不同的控件 ID；不会复制后台会话或协作记录。

## 后台与状态

- 新增 chat.pinned，复用搜索的元数据查询函数，按真实 Hive 工作区过滤，解析成员当前名称，保留用户自定义标题，按原活动时间和会话 ID 排序。置顶读写不启动 Agent。
- 全局读取覆盖全部置顶，不沿用搜索的 100 条结果上限。已移除/移除中的工作区过滤，空列表不制造示例记录。
- 刷新串行合并，连接代数及刷新版本阻止旧响应覆盖新连接或更新后的请求。失败保留上一次成功快照并显示错误，可刷新重试。
- 当前项目聊天/成员列表刷新时合并已有快照，更新标题、归属及活动时间；不对每批流式事件查询全部项目，也不覆盖独立保存的置顶状态。
- 搜索、项目行和置顶行复用 navigate_to_session：检查连接、关闭与项目移除状态，为尚未加载的目标补入记录，然后走原有选中、打开、草稿和历史恢复流程。
- 工作区移除清理对应置顶视图，后台重连重新读取；没有新 store、依赖、Hive 协议或 SQLite schema。
