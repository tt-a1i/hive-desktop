# 界面字号

任务 #11。只读查看本机 Cindy 0.1.128 外观页，确认界面字号、恢复默认及与代码/终端字号分开的配置；随后返回原新会话页，没有修改参考应用设置或发起模型请求。

## 行为

设置 → 外观新增界面字号，12–20 px，默认沿用 GPUI 的 16 px。减小/增大立即生效，上下限按钮禁用；恢复默认只恢复字号，保持已选主题。阅读预览随界面一起变化，设置搜索支持字号/font/size/text 等关键词。

使用 gpui-kit 的 Theme::update 同步字体尺度和组件主题，根窗口沿原生 rem_size 渲染；主题或系统外观变化后重新应用用户字号。不另建缩放层、不缩放窗口物理尺寸。不提供独立代码/终端字号、字体文件管理、壁纸或主题导入。

复用 desktop-appearance.json 及原有临时文件替换写入：兼容旧主题字符串，首次成功修改后保存 mode/font_size 对象。范围外字号或坏 JSON 明确报错，不在读取时覆盖原文件。写入成功后才更新内存与界面；失败保留原字号并提示。
