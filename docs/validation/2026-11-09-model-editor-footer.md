# 模型编辑固定操作栏与窄窗保存

2026-11-09，源码Mac原生验证；此项尚未打新包。隔离Pi配置：一个本地回环占位接口，31个合成模型、长显示名及提供商headers，不使用真实凭据或执行模型。原有真实会话数据仅复制为窗口工作区背景。

## 实际问题与修改

1184×1504截图像素的窄窗中，原模型表单的保存/关闭落在视口外。Tab从名称经过Token与能力控件到保存时，页面没有滚动到按钮，用户看不到当前操作。

将原表单动作原样提取至模型页底部固定栏；列表/表单正文使用原滚动句柄并加入已有滚动条，编辑时暂时收起模型列表，避免Tab穿过几十个模型行才到固定操作。关闭表单、保存成功后恢复列表；原有草稿恢复、未保存确认、字段和保存回调保持。编辑时提示随操作栏呈现，提供AX状态节点。没有改模型配置API、文件写入、认证或全局默认。

## 实际验证

- 更矮的1184×1104及1184×1504像素窗口，保存/关闭与未保存提示均可见。
- 输入非法Token，点击固定保存，原校验错误“Token数量需要正整数，或留空使用默认值”在操作栏及AX树可读；配置文件内容与初始夹具相同。修正8192并保存，成功返回列表。
- 名称输入起5次Tab直接到可见保存按钮，截图有焦点环；空格激活保存成功。落盘名称为KEYBOARD_SAVE_PROOF · 中文，上下文8192。
- 逐对象断言最终配置只改上述两字段，其余30个模型、提供商headers及其他字段与原夹具完全相同。
- 完整Cmd+Q退出0，冷重开重新进入编辑器，名称/8192读回正确，保存按钮禁用、无未保存状态；再次正常退出0。
- 加入夹具headers后已有草稿与外部配置版本不同，原草稿恢复提示及关闭确认真实出现；退出该旧夹具草稿后重新编辑，未绕过版本冲突检查。没有将这一步当作配置损坏。
