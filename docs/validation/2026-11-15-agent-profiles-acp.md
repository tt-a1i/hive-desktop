2026-11-15。本地开发分支已集成四后端固定配置、必要桌面入口及 ACP 生产注册。本文区分实际模型、实际界面、受控协议和包内验证；不代表完整产品交付，用户安装实例及 current/candidate `837abd1` 未替换。跟踪于 #39、#52。

## 四后端配置

配置有固定 ID 和不可覆盖的连接 revision。聊天、成员、模型目录、工作树、历史分叉和冷恢复使用同一引用。更名不切换历史身份；停用阻止运行，保存历史仍可读。旧配置迁移带有来源标记，不宣称找回了历史账号。

独立审查发现并修复两项问题：默认配置和旧设置分次保存可能在失败后不一致；Claude 离线历史可能读取宿主默认目录。现在默认程序、三个默认 revision 和兼容设置在同一 SQLite 行原子保存；只读历史使用固定配置的官方 SDK 读取路径。提交前失败、提交后响应丢失、冷读、并发编辑和未知配置不回退均已复验。没有运行 Claude 账号或模型。

生产 API 及真实 Hive/SQLite、受控进程另验证了同类配置的 argv/configDir、模型目录和账号状态/额度请求隔离、Worker 归属、默认升级后的旧 revision 实际重启、工作树意图和历史继承。合成账号响应不是实际厂商账号验证。配置只存非机密启动参数和路径，不复制认证文件；同名或不同名配置均不自动代表不同账号。

## Mac 实际界面

隔离 QA 使用受控 Codex peer，无模型请求。配置创建后重复保存保持同一 ID；更名、停用、启用、刷新和非法参数保留草稿均实际操作，并用只读数据库核对。成员及独立工作树保留对应 revision；专属包装器记录所用命令、argv 和配置目录，未记录凭据。

后续原生程序还验证了错误状态的可访问名称及“按已保存配置新建会话”。创建两个聊天均保留指定 `r2`，没有发送消息；冷重开保留配置、会话引用、原聊天草稿和已关闭的测试初始化角色。

同时修复了离屏 AXPress 的实际错误：原实现按完整布局中心合成鼠标事件，可能点到设置背景。现在标准点击回调按目标调用，不发送背景鼠标事件。离屏、可见、聚焦后三种保存都通过实际 AX 操作和持久化核对。弹出菜单仍未在 AX 树中暴露；当前证据不能证明视觉上是否打开，也不能归因于此补丁。没有把这条路径标为通过。

## ACP

ACP 使用明确配置的 stdio 程序，不创建虚构默认路径。已接生产 JSONL、共享 Hive 运行时和私有 MCP team bridge。握手、工具/思考、原生权限选项、取消、持久化和恢复均按协议处理；模型、模式和图片等本片未实现能力明确拒绝。

受控 ACP 子进程通过真正的 MCP tools/call、team CLI、Hive HTTP/SQLite 完成派单、messages/seen/report，并回到原主控会话；厂商回合结束不会伪装成 Hive 汇报。被动打开不启动进程；不支持 loadSession 时只读本地历史，不新建替代会话。发送后结果不明时不自动重放，用户可预览并明确放弃指定等待项；原 sent 未知状态和 Hive 审计保留，写盘失败和响应丢失有专项验证。

独立生产注册审查另发现并修复慢 MCP 握手被误拒及启动等待阻塞退出的问题。1.6 秒延迟握手通过；相同关闭场景从约 30 秒降到约 10 毫秒，并核对受管理子进程退出。四后端相关回归通过。

另核对真实 Codex MCP 实现后修复环境传递：它按允许列表继承环境，不能依赖 ACP 父进程中的私有绑定。临时 MCP descriptor 现在显式携带绑定与就绪证明，并从 ACP 父环境移除这两项；它们不写入配置或命令行。受控 peer 按真实允许列表启动 MCP 后，共享 Hive 链路通过；嵌套 JSON 错误反射中的凭据也有专项脱敏检查。

官方 `@agentclientprotocol/codex-acp@2.6.0` 与已安装 Codex `0.169.0` 已做隔离零模型预检，初始化、新建原生会话及生产 MCP 工具发现通过，原生返回基础模型为 Terra。实际空会话还未生成 rollout，随后 load 失败；未新建替代、发送提示或修改账号配置。此次预检未保留实际 provider 字段，不能宣称完整模型身份或冷恢复已验证。新一轮混合协作必须从原生响应核对模型和 provider，并独立记录预算。预检原始失败和版本化守卫证据保留于 `.artifacts/functional-parity/acp-vendor-plan/`。
