# 协作任务编辑验证

2026-11-07，macOS。验证使用实际 GPUI 界面、现有 Hive HTTP 任务接口和 Markdown 文件；任务内容是隔离的合成夹具，没有调用模型。证据位于 `.artifacts/task-editor-ui-proof/`，包含 `receipt.json` 和修改前、保存后、外部修改后的任务文件副本。

原生界面走查覆盖：

- 输入并保存中文多行 Markdown，返回预览核对内容；切换到聊天和刷新后，未保存草稿仍保留。
- 外部直接修改任务文件后再保存，界面显示冲突，外部文件逐字未被覆盖，草稿保留。
- 两个工作区的草稿独立；保存 B 后切回 A，A 的草稿没有串入 B。取消 A 的草稿后读取到外部修改后的最新文件。

保存归属于发起时的工作区草稿，页面隐藏时仍可结算；这一点经过独立源码审查。CUA 没有人为延迟请求，因此没有验证保存进行中切换页面的精确时序。

冲突检查是先 GET 比较再 PUT，并非原子 compare-and-swap；两步之间的外部修改仍可能被覆盖。草稿只保存在应用进程内，退出应用后不保证恢复。任务编辑的验证不代表整个协作工作台或完整应用已完成。
