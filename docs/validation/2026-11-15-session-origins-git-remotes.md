## 历史会话身份

修复成员从 A 换绑 B 后的两个实际缺口：历史报告不能按当前绑定打开 B；A 的当前绑定为空也不能在继续时改用主控。按 [ADR 0003](../adr/0003-preserve-original-session-identity.md) 保存首次身份，区分本版本新建、可信归属和旧记录未知。精确派单来源可以回填归属；标题、时间和重复原生 ID 不能作为证据。当前绑定和准确派单来源冲突时拒绝运行。

用户明确继续空闲 A 时仍激活原 Worker，保留原生会话和执行目录。B 忙碌、有持久队列或未结派单时拒绝换绑；停止旧运行后再次核对。归属未知、冲突或原成员已删除时从磁盘展示只读历史，不创建 SDK 会话、厂商进程或唤醒队列；不完整读取显式返回警告。Hive 的账本、派单、seen/report/accept 不回滚或复制。

`dispatch.session` 仅返回保存来源中的原会话，校验工作区与可选原 Worker，缺少来源或执行目录时明确失败。桌面报告、待处理报告、协作和工作流入口已接该接口；日常成员“当前会话”仍表示 B。只读快照保留草稿，禁止发送、继续、模型/推理修改和会启动原生会话的设置、命令及用量查询。页面、连接、会话和工作流详情切换会使迟到响应失效，打开快照前核对请求/当前/响应工作区及会话身份。

真实临时 Hive、SQLite、Git 和无模型 Pi SDK 检查通过：A→B→明确继续 A 保持 Worker，主控 run 不变；B 排队/忙碌时不加载 A；准确来源冷回填、删除成员、未知旧记录、身份冲突和缺失目录均按预期拒绝。`session-origin-index.ts` 与 `historical-session-identity.ts` 经独立复核和重跑，零模型请求。桌面独立审查发现的自动查询、工作流迟到导航、错误工作区快照三处边界均已修复，5 项定向测试及 Mac/MSVC 检查通过。Rust 完整测试最终为 80 项通过、1 项显式忽略的子进程 fixture；新历史入口的实际窗口操作仍待验收。

## 推送与 GitHub PR

远端与分支必须明确选择，列表只读本地配置，预览才联网。支持单一、相同 fetch/push URL；推送源固定为预览的提交 OID，不自动提交、fetch、设置 upstream 或跟随 tags。仅新分支、已同步或能证明快进的状态允许执行；分叉和本地缺少远端历史明确拒绝。快进证明禁用 replace/graft 虚拟图，随后用精确旧远端 OID 条件保护原生 push；不存在供用户绕过祖先检查的强推选项。保留原生 hooks、凭据及正常 tracking ref 更新语义。

PR 首版支持同仓库 GitHub.com。显式核验仓库、head、base 和返回 URL；未推送预览中的 head 不创建。用户填写标题、正文并选择草稿，更新只针对准确预览的现有 PR。使用原生 `gh`、隔离临时目录及私有 `--body-file`，不依赖继承的仓库路由，不登录或修改全局账号。非快进、过期及参数校验失败返回未执行；原生写入已开始而无法确认的结果返回 `unknown`，不得自动重试。

错误边界已补认证头整段、URL 完整 userinfo（含多个 `@`）及访问参数脱敏；假秘密的真实 stderr 与受控 `gh` 回归和独立复现均通过。远端 CAS 独立复现确认：预览 A 后、push 启动前变成待推提交的另一祖先 C，操作拒绝且保留 C；新分支并发创建也保留他人引用。replace/graft 不能伪造可推状态。

实际 JSONL 入口的 `git-remotes-wire.ts` 通过真实本地 bare Git 和受控 `gh` 检查：列表/预览/推送、工作树/根目录隔离、忽略 payload 路径和可执行程序覆盖、过期拒绝、PR 创建/更新/错误与不确定结果、私有正文文件及 RPC 脱敏。真实 pre-push gate 证明关闭响应和推送响应均等待 hook 释放，随后 remote OID 与正常退出吻合。远端查询也纳入退出等待，避免网络或凭据子进程脱离后台生命周期。
