# 会话名称与原生编辑验证

2026-11-07。

用户在同一项目保留多个主控和成员会话时，需要能在侧栏识别各自用途。会话名称保存到现有桌面索引，独立于成员名称、模型身份及厂商会话文件。显式名称也可以是“新会话”，后续输入不会把它替换为第一条提示词。

## 实际验证

- `checks/session-titles.ts` 使用真实 Hive HTTP/SQLite 工作区和文件索引，为内置 Pi、Codex、外部 Pi、Claude 四种记录改名，覆盖中文、emoji、空值、控制字符、长度、旧记录及完整 runtime 重启。磁盘目标被临时占用时，失败写入保留原来的内存记录和磁盘数据。
- `checks/team-runtime.ts` 在真实内置 Pi/CLI 队列暂停后执行用户输入，确认手工名称“新会话”在输入与重启后仍保留。该检查还验证原有派单及显式汇报，使用 GPT-6.1 Terra 的模型配置，未发送模型请求。
- `scripts/check-package.mjs` 通过便携包的真实 JSONL RPC，覆盖四后端创建记录、改名、列表更新与拒绝空名称。
- macOS 打包应用使用临时数据目录，实际点击成员会话、编辑中文与 emoji 名称、保存、取消、切换会话、退出并重开。侧栏、标题与重新编辑框一致显示自定义名称，成员草稿“保留这条成员草稿。”在切换及重启后保留。
- 原生窗口验证 Enter 保存、Escape 取消。一次空名称提交显示错误后，改为有效名称成功保存时，错误反馈会消失。
- Windows 原生检查已增加会话改名和真实索引回读。GitHub 账户计费限制导致新 job 未启动，该部分尚未运行。

此前的 CUA `typeText` 操作未写入中文，改用系统粘贴后输入成功。这次未验证系统中文输入法的组合输入。

没有启动新的模型回合，没有修改用户全局 Agent 配置。Windows 新版本交互、Claude 真实模型协作、正式签名发行及完整产品验收仍待完成。
