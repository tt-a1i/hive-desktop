# 会话执行目录独立于团队工作区

独立工作树属于会话的执行位置，Hive 工作区继续拥有唯一团队账本、成员身份和派单责任。将每个工作树建成新 Hive 工作区会割裂协作；直接改写工作区路径又会移动所有成员的代码根，因此保留工作区路径，并为会话持久化可选执行目录。旧会话没有该信息时使用原项目目录。

首次创建原生会话前固定执行目录，已有原生线程不通过修改路径原地迁移。新工作树由桌面在专有数据目录中管理；项目是仓库子目录时保留相对范围。冷恢复必须核对原仓库与工作树身份，缺失时明确停止，不能回落到团队根重放输入。Git、文件引用、历史、产物和会话终端均须解析实际来源会话的执行目录；团队工具仍以原工作区和成员身份操作账本，归档会话保留代码，清理工作树是独立的明确操作。
