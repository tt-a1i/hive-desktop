# 会话原始归属不随当前绑定改变

一个成员先在会话 A 接收派单，之后可以切到会话 B。清除 A 的当前绑定不表示 A 从未属于成员。原先仅保留当前绑定，导致旧报告导航打开 B，继续 A 时还可能因绑定为空而选择主控，改变实际团队权限和派单接收者。

会话首次绑定时保存不可变的 `originAgentId`，当前 `agentId` 仅表示当前绑定。新记录明确标为尚未首次绑定；旧记录的可靠当前绑定或已持久化的准确派单来源可以确认原始归属。没有这些证据的旧记录标为未知，不能按标题、时间、目录或成员当前最后会话猜测。Hive 的成员最后会话记录会被后续会话覆盖，不能据此完整重建历史。

用户明确继续历史会话时，后台使用仍存在的原成员身份，并复用运行中、待处理输入和未结派单保护。成员已删除或归属未知时，只读展示可恢复的历史与不完整提示，禁止启动后端、发送、继续及更改原生会话设置。只读状态属于准确工作区与会话快照；切换后重新核验，不作为当前运行或停止其他进程的凭据。

历史报告、协作派单及工作流的成员会话入口通过派单执行来源解析到原会话。没有来源、身份冲突或原执行目录不可用时明确失败，不替换为成员当前会话或团队根目录。日常成员管理中的“当前会话”继续表示当前绑定。历史内容、原生会话与 Hive 协作账本保留，修复不会回滚或复制派单、确认和汇报记录。
