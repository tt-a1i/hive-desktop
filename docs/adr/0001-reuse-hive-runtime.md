# 通过 Hive 执行器接缝接入结构化 Agent

桌面端继续使用 Hive 的唯一协作账本、成员身份、派单、seen 检查、汇报 outbox 和恢复规则；在运行时装配层提供可注入的执行器，令 Pi SDK 等结构化后端与已有 PTY 后端共用这些业务流程。当前以固定 npm 版本的可重现 pnpm 补丁开放该接缝，保留默认 PTY 行为，桌面侧负责结构化会话的执行和事件。

直接复用 Codex App controller 接口只能覆盖主控且绑定 Codex 通知；重建桌面协作账本会让两套语义分叉。因此采用同时覆盖主控与 Worker 的执行层扩展。补丁需要随 Hive 版本升级验证，稳定后应将通用装配接口回收到 Hive 上游；不能把模型回合结束、取消当前回复或关闭窗口混同为任务汇报与验收。
